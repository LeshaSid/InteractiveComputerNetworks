# 🌐 Компьютерные сети — интерактивный курс

Интерактивный сайт для изучения компьютерных сетей и подготовки к лабораторным работам: теория, разбор каждого задания с ответами, тесты, флеш-карточки, симулятор Cisco IOS и интерактивная модель OSI — всё прямо в браузере, с телефона и с ПК.

**Технологии:** чистый HTML / CSS / JavaScript. Без сборки, без фреймворков, без сервера. Прогресс хранится в `localStorage` браузера.

## Возможности

- 📚 **Общая теория** — OSI и TCP/IP, физический и канальный уровни, ARP, Cisco IOS, топологии (глубже методички)
- 📖 **Лабораторные работы** — для каждой работы: обзор, теория, пошаговый разбор заданий с вопросами из методички и ответами, скриншоты
- ✅ **Тесты** — квизы с мгновенной обратной связью, лучший результат сохраняется, разбор ошибок с повторением
- 🃏 **Флеш-карточки** — термины и определения, листаются свайпом (мобильные) или кнопками; перемешивание и режим «только новые»
- 🖥️ **Симулятор Cisco IOS** — отработка режимов, `show`, паролей, баннера прямо в браузере
- 🧱 **Интерактивная модель OSI** — 7 слоёв, PDU, протоколы + анимация инкапсуляции
- 🔌 **Тренажёр T568A/T568B** — распиновка RJ-45: схема, сравнение и тест на запоминание
- 🧪 **Симулятор Packet Tracer** — учебная топология, IP Configuration, ARP, ping, журнал кадров, физические модули
- 🔍 **Поиск** — по всей теории, заданиям, вопросам, карточкам и шпаргалке (Ctrl+K или `/`)
- 🌗 **Тёмная / светлая тема** — переключается кнопкой внизу меню, запоминается
- 📱 **Адаптивность** — удобно читать с телефона (боковое меню → бургер)
- 💾 **Прогресс** — отмеченные задания, результаты тестов, чек-листы сохраняются локально; экспорт/импорт JSON и сброс — в меню
- 📴 **PWA** — офлайн-кэш после первого открытия (нужен http/https, не file://)

## Локальный запуск

Просто откройте `index.html` в браузере (двойной клик) — всё работает и через `file://`.

Либо через локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## 🚀 Размещение на GitHub Pages (приватный репозиторий)

Сайт статический — подойдёт любой хостинг. Ниже — бесплатный вариант с GitHub Pages.

### Вариант A. Приватный репозиторий (рекомендуется)

> Важно: приватные репозитории доступны на всех аккаунтах GitHub. GitHub Pages для приватного репозитория работает на публичном GitHub Free? — **Pages разворачивается из приватного репозитория, но сама страница по ссылке доступна всем, у кого есть ссылка.** Если нужен полный доступ только себе — используйте вариант B.

1. Создайте репозиторий на [github.com](https://github.com) (Private).
2. Загрузите все файлы сайта в него:

   ```bash
   cd InteractiveComputerNetworks
   git init
   git add .
   git commit -m "Интерактивный курс по компьютерным сетям"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages**.
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)`
   - Сохраните (Save).

4. Через 1–2 минуты сайт появится по адресу:
   `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПО/`

   ⚠️ **Важно про приватность приватного репозитория:** если репозиторий приватный, но Pages включён — страница **публична по ссылке** (без авторизации). Это удобно для телефона: просто открываете ссылку. Если хотите, чтобы доступ был только по паролю/логину — GitHub Pages этого не умеет из коробки; можно закрыть весь репозиторий той же учетной записью (Pages перестанет работать для всех, кроме владельца), либо выбрать вариант с GitHub Pro ( Pages для приватных репозиториев с проверкой доступа), либо использовать Cloudflare Pages / Netlify с защитой паролем.

### Вариант B. Только для себя (без публичной ссылки)

- **GitHub Codespaces / GitHub Desktop** — можно открывать приватный репозиторий и запускать `python3 -m http.server` в Codespace, ссылка временная, доступна только вам.
- **Cloudflare Pages** — бесплатный тариф, приватный Git-репозиторий, сайт по ссылке; можно включить «Access» (ограничение по email/паролю).

### Если репозиторий публичный — самый простой путь

1. `git push` в публичный репозиторий.
2. **Settings → Pages → Deploy from branch → main / root → Save**.
3. Ссылка `https://логин.github.io/репо/` работает сразу.

### Частые проблемы GitHub Pages

- **404 сразу после включения Pages** — подождите 1–2 минуты и обновите; проверьте, что выбрана ветка `main` и папка `/ (root)`.
- **Сломанные пути к картинкам** — в этом проекте все пути относительные (`assets/img/...`), так что проблем быть не должно.
- **Не сохраняется прогресс на телефоне и ПК одновременно** — `localStorage` привязан к устройству/браузеру. Для синхронизации между устройствами потребуется аккаунт и бэкенд (вне рамок статического сайта).

## 🧩 Как добавить новую лабораторную работу

Модель расширения: **блок-контент**. Страницы собираются из массива объектов-блоков (`{type: "h2" | "p" | "img" | "table" | "cmd" | "qa" | "quiz" | ...}`). Ничего в ядре менять не нужно.

**Быстрый старт:** `./tools/new_lab.sh 3` — скопирует шаблон из `lab1` в `content/labs/lab3/`. Или возьмите готовую заготовку `content/labs/lab2/` (шаблон) и заполните её.

1. **Создайте папку** `content/labs/labN/` со стандартными файлами (скопируйте из `content/labs/lab1/` и отредактируйте):

   | Файл | Что хранит |
   |---|---|
   | `meta.js` | Метаданные: id, номер, название, цель, список PKA-файлов, ID теста и колоды карточек |
   | `theory.js` | Блоки краткой теории перед заданиями |
   | `tasks.js` | Массив заданий: `{id, num, title, intro, blocks}` |
   | `quiz.js` | Вопросы квиза `{q, options, correct, explain}` |
   | `flashcards.js` | Карточки `{term, def}` |

2. **Зарегистрируйте лабораторную** — добавьте одну запись в `content/registry.js`:

   ```js
   {
     id: "lab2",
     num: 2,
     title: "Настройка VLAN и trunk",
     icon: "🔀",
     desc: "Короткое описание для карточки на главной.",
     tasksCount: 5,
     contentDir: "content/labs/lab2/"
   }
   ```

3. **Подключите скрипты** в `index.html` (рядом с подключением lab1):

   ```html
   <script src="content/labs/lab2/meta.js"></script>
   <script src="content/labs/lab2/theory.js"></script>
   <script src="content/labs/lab2/tasks.js"></script>
   <script src="content/labs/lab2/quiz.js"></script>
   <script src="content/labs/lab2/flashcards.js"></script>
   ```

4. **Картинки** положите в `assets/img/labN/...` и указывайте относительные пути в блоках:

   ```js
   { type: "img", src: "assets/img/lab2/screenshot1.jpg", caption: "Подпись" }
   ```

5. **Откройте сайт** — новая лабораторная автоматически появится в меню, на главной, в поиске и в прогрессе.

### Типы блоков контента

| Тип | Параметры | Что отображает |
|---|---|---|
| `h2`, `h3` | `text` | Заголовок (с якорем) |
| `p` | `text` | Абзац, поддерживает `**жирный**`, `*курсив*`, `` `код` ``, `[ссылка](url)` |
| `ul`, `ol` | `items: []` | Список |
| `table` | `head: [], rows: [[]]` | Таблица |
| `img` | `src`, `caption`, `wide?` | Картинка в рамке с подписью |
| `cmd` | `lines: []`, `title?` | Блок терминала (подсветка команд, кнопка «копировать») |
| `callout` | `kind: info\|warn\|danger\|tip\|deep`, `title`, `text` | Цветная выноска |
| `qa` | `q`, `a` | Вопрос с раскрывающимся ответом |
| `checklist` | `id`, `items: []` | Чек-лист с сохранением в localStorage |
| `tabs` | `tabs: [{title, blocks}]` | Вкладки |
| `quiz` | `id` (из `Site.quizzes`) | Виджет теста |
| `flashcards` | `id` (из `Site.decks`), `title?` | Виджет флеш-карточек |
| `osi` | — | Интерактивная модель OSI |
| `cli` | `device?` (`switch`) | Симулятор Cisco IOS |
| `pinout` | — | Тренажёр распиновки T568A / T568B |
| `pt` | `topology?` | Учебный Packet Tracer: топология, IP, ARP, ping, capture, модули |
| `hr` | — | Разделитель |

## Структура проекта

```
index.html                     # SPA-каркас, подключение скриптов
manifest.json                  # PWA-манифест
sw.js                          # Service Worker (офлайн, только http/https)
assets/
  css/main.css                 # Темы, layout, адаптив
  css/components.css           # Блоки контента, виджеты
  img/lab1/methodic/           # Рисунки из методички (переименованы семантически)
  img/lab1/reports/            # Скриншоты из отчётов
  js/app.js                    # Роутер, меню, тема, поиск, страницы, экспорт прогресса
  js/renderer.js               # Рендерер блоков контента
  js/search.js                 # Индекс и поиск
  js/widgets/                  # quiz, flashcards, osi, ios-cli, pinout, progress
  js/pt/                       # Симулятор Packet Tracer (core / engine / ui)
content/
  registry.js                  # Список лабораторных (единая точка расширения)
  theory.js                    # Общая теория
  cheatsheet.js                # Шпаргалка Cisco IOS
  questions.js                 # Контрольные вопросы (с ответами)
  labs/lab1/                   # Контент лабораторной 1
  labs/lab2/                   # Шаблон лабораторной (заполните и зарегистрируйте)
tools/extract_assets.py        # Скрипт извлечения картинок из PDF/DOCX
tools/new_lab.sh               # Скаффолдинг новой лабораторной
```

## Скрипт извлечения ассетов

Если появятся новые методички/отчёты в PDF или DOCX:

```bash
# Для PDF: извлекает все встроенные картинки
pdftotext -layout "методичка.pdf" /tmp/methodic.txt
pdfimages -png "методичка.pdf" /tmp/figs/fig

# Для DOCX: картинки лежат внутри архива
unzip "отчёт.docx" -d /tmp/docx_ex
# -> /tmp/docx_ex/word/media/

# Конвертация и оптимизация (Pillow)
python3 tools/extract_assets.py --src /tmp/figs --dest assets/img/labN/methodic
```
